# DemoNotes

Sample installable business module for FYD CMS module lifecycle testing.

## Install

```bash
cp -r contrib/DemoNotes app/Modules/DemoNotes
```

Then open **Administration → Modules** and install **DemoNotes**.

## Features

- **Demo Notes** — simple notes CRUD
- **Demo Tags** — simple tags CRUD

Both appear under sidebar group **Demo Module** (right panel).
